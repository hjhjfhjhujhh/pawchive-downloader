## 主要功能

- **一键下载整帖**：左下角悬浮面板点一下，帖子里的图片全部入队；
  附件与视频左键（或中键）点击即下载，保留原文件名。
- **自动归档**：保存到 `下载\pawchive\作者-平台-作者ID\帖子ID-标题\`，
  图片按帖子内顺序编号，同名文件不会覆盖。
- **多帖子并行**：所有标签页共享一个下载队列，任务在多个帖子之间交错进行，
  切换页面、刷新、关闭标签页都不会中断；并行数可调（默认 8）。
- **进度一眼可见**：面板左下角显示 `本帖子：X(Y/Z)` = 全局剩余 / 本帖剩余 /
  本页已提交；弹窗里能看到逐个文件的排队、下载、完成、失败状态，
  可单独取消某个文件或一键中止。
- **未存档帖子也能下**：站点还没存档的帖子只能看预览图，此时面板与弹窗会
  自动切换成「下载全部缩略图」（橙色按钮），不会白跑一趟。
- **阅读辅助**：正文上方插入缩略图条（点图定位原图、角标按钮直接下载单张）、
  面板顶部带上/下帖导航、面板可拖动到任意位置、作者主页给未存档帖子打红叉。
- **可调设置**：跳过每帖前/后 N 张、标题屏蔽字（默认剔除 `(P■■■■■ ■■■box)`、
  `pa■■■■■`）、自动跳过封面、允许重新下载已完成文件、自定义下载目录。
- **广告拦截**：站点注入的弹窗广告会被拦掉，同时不影响正常打开链接。

## 安装（Windows）

1. **装 Python**：安装 Python 3.8+，安装时勾选 **Add python.exe to PATH**。为什么不把python文件打包？哈哈我不干
2. **放好下载引擎**：从 aria2 发布页下载 Windows 版，解压后把其中的
   **`aria2c.exe` 复制到 `helper` 文件夹**里。
3. **注册辅助程序**：双击 `helper\install.cmd`，看到「宿主清单」「注册表」
   几行输出即为成功，按任意键关闭。
4. **加载扩展**：打开 `edge://extensions`（或 `chrome://extensions`）→ 打开
   「开发人员模式」→「加载解压缩的扩展」→ 选择本目录下的 **`extension`** 文件夹。
5. **启动辅助程序**：双击 `helper\run-as-admin.cmd`，在 UAC 弹窗点「是」，
   **保持这个窗口打开**（关掉它下载就会停止）。

## 使用

打开任意 pawchive / kemono 帖子页，左下角会出现悬浮面板：

- **下载帖子全部图片**：整帖图片入队；
- **复制图片链接**：把原图链接复制到剪贴板（如果你想用其他软件下载的话）；
- 点到附件/视频链接时直接下载单个文件；
- 需要更多设置时点浏览器工具栏上的扩展图标。

## 常见问题

- **面板显示「aria2 引擎未就绪」**：确认第 2、3 步做了，再点弹窗里的
  「重新连接辅助程序」，随后等待一分钟左右；仍不行就重新双击 `helper\run-as-admin.cmd`。
- **提示连不上辅助程序**：`run-as-admin.cmd` 的窗口被关掉了，重新打开即可。
- **下载目录**：默认系统「下载」文件夹，可在扩展弹窗里改成任意路径（未测试！）。
  重复下载文件时，目标目录里同名文件会自动存成 `xxx (1).jpg`。可禁用重复下载功能（体验有限）。
